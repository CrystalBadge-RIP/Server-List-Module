# Server-List-Module
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.1.

This module is for dynamically add and fetch the server list without have to touch the backend.
This include automatic sharding which use to lower the rate of partition which is useful for large server list.



NOTE: This module is currently experimental. The documentation and the video will be made sometimes in January 2027.
